# v0.8.0 — Programa de Indicação

**Onda:** Aquisição e viralização.  
**Data:** 2026-08-20.

## Resumo

Lançamos o motor de indicação entre usuários da Orca. Agora qualquer usuário logado pode convidar outros freelancers e acompanhar o status de cada indicação direto no app.

## O que mudou

### Para o usuário

- **Página `/convidar`** (menu lateral "Indicar e ganhar"):
  - Link único de indicação com código de 8 caracteres.
  - Botão de copiar link.
  - Lista de pessoas indicadas com status (`pending`, `converted`, `paid`).
  - Explicação do benefício: desconto na primeira assinatura para quem se inscreve e créditos para quem indicou.

- **Cadastro com código de indicação**:
  - URL `/register?ref=XXXX` armazena o código automaticamente.
  - Ao criar a conta, o código é vinculado ao novo usuário via Edge Function `signup-guarded`.

### Para admin

- Novas tabelas no banco: `referrals` e coluna `referral_code` em `profiles`.
- Backfill automático gera código para usuários existentes.
- Triggers geram código para novos cadastros.

## Métricas esperadas

- Taxa de compartilhamento de link por usuário ativo.
- Conversão de cadastros vindos de indicação.
- Custo de aquisição reduzido via canal orgânico.

## Próximos passos

- Conectar o webhook do Stripe para marcar indicações como `paid` quando o usuário indicado assinar o Premium.
- Definir regra de crédito/recompensa (desconto na próxima fatura, crédito em conta etc.).
- Exibir saldo de créditos no dashboard.
